The rules

Do this.
Not that.

Do
  • Give full context: event, audience, tone, deadline — before any prompt
  • Paste a real ASB sample so the model mirrors what already works
  • Use it for first drafts, then edit yourself — your voice stays yours
  • Always read the output before hitting send
  • Translate fast, then have a native speaker do the final pass
  • Ask for structure first, then layer in what only you know
  • Tell the model what you don't want as much as what you do
Don't
  • Copy-paste output into a client email without reading it
  • Use it for decisions on pricing, operations, or contracts
  • Trust AI-generated numbers — verify stats independently, always
  • Skip the brand context and complain the output "sounds generic"
  • Use it to replace your judgment on tone and timing
  • Treat the first draft as final — one iteration is almost never enough
  • Input confidential client data without checking our data policy
