Motion · Transições

Movimento
com propósito.

Três velocidades. Três funções. Passe o mouse nos cards pra sentir.

--transition-fast
0.15s ease-out
Feedback instantâneo: hover, click, toggle.
--transition-default
0.20s ease-out
Padrão: cards, botões, mudança de estado.
--transition-slow
0.35s ease-out
Ênfase: modal, drawer, reveal de conteúdo.

Princípios

  • Movimento é função, nunca decoração.
  • Hover sobe 3px. Press desce 2px. Sempre ease-out.
  • Nada de mola. Energia controlada, não saltitante.
  • Respeite prefers-reduced-motion.

Princípios · Aplicação

Como
usar.

Do

Voz e tom

  • Bold e aspiracional — escreva com carga emocional
  • Segunda pessoa (você) — fale direto com o cliente
  • Caps em headlines maiores e CTAs principais
  • "ABSOLUT Sport" — sempre escrito completo
  • Marcos oficiais com ™ — Libertadores™, Sudamericana™
Don't

Voz e tom

  • Não use frieza luxo — não somos cold luxury
  • Não escreva apenas "Absolut" sem o "Sport"
  • Não exagere em emojis em peças institucionais
  • Não misture vozes — defina uma e siga
  • Não use linguagem corporativa genérica
Do

Fotografia

  • Full-bleed photography — multidão, estádio noturno
  • Overlay escuro de baixo para cima — legibilidade
  • Highlights quentes, contraste dramático
  • Iluminação noturna de estádio é a paleta
  • Pessoas em movimento, emoção real capturada
Don't

Fotografia

  • Sem ilustrações desenhadas à mão
  • Sem padrões decorativos planos
  • Sem stock photos genéricas de business
  • Sem imagens AI-generated em peças finais
  • Sem filtros saturados de Instagram dos anos 2010
Do

Tipografia

  • SoulCraft GX para todo headline de marca
  • Barlow para corpo, UI e menus
  • JetBrains Mono para preços, dados e código
  • Use o truque do "0 → O" em texto SoulCraft
  • Respeite a hierarquia: Hero · Display · Headline · Title · Body
Don't

Tipografia

  • Não use Google Fonts aleatórias por estética
  • Não misture mais de 3 famílias na mesma peça
  • Não use fontes com serifa em material institucional
  • Não estique ou aperte SoulCraft — ela já é condensada
  • Não use ALL CAPS em corpo de texto longo
Engenharia · Implementação

Para
devs.

Importe os tokens e a página herda toda a paleta, tipografia e escala. Funciona em qualquer HTML/CSS/React.

1. Importe o CSS de tokens

Cole no <head> antes de qualquer estilo seu. Todas as variáveis ficam disponíveis globalmente.

<link rel="stylesheet" href="https://design.absolut-sport.com.br/colors_and_type.css">

2. Use os tokens via CSS Variables

Cores, tipografia, spacing, radius — tudo via var(--token). Nunca hardcoded.

/* ✓ correto */ .cta { background: var(--color-blue); color: var(--color-white); font-family: var(--font-display); padding: var(--space-3) var(--space-6); border-radius: var(--radius-sm); } /* ✗ errado — não use valores hardcoded */ .cta { background: #155F97; padding: 12px 24px; }

3. Para texto SoulCraft, ative o "Zero-to-O"

Script que troca todo "0" por "O" maiúsculo dentro de elementos SoulCraft. É uma assinatura da marca — números viram +5oo, 1oK, 12o×.

<script src="https://design.absolut-sport.com.br/zero-to-o.js"></script>
